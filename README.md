# Analyse de performance d'un service Helpdesk

## Contexte

Projet réalisé dans le cadre d'un stage à l'OCP.

## Objectif

Analyser les performances du Helpdesk à partir des tickets afin de calculer les KPI, construire un tableau de bord Power BI et développer un modèle de prédiction des dépassements de SLA.

## Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-Learn
- Power BI
- Git
